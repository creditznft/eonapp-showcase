Current help boundary

          
Self-service guidance plus private case workflow

          
EONAPP subscriptions are available only through the hosted Dodo checkout opened from Billing. EONKEYS are non-cash referral unlocks for selected individual features; sharing alone never grants a key, and browser state cannot award a plan or key. No wallet or chain payment, token, payout, marketplace sale or provider-credit reward is active. Private case IDs now exist, but a response-time promise is not made.

          
There is no premium support queue, manual plan activation, manual EONKEY grant or guaranteed response time. Case review is an operational workflow, not an automatic commercial action. Billing lifecycle changes are accepted only from signed Dodo events and the server entitlement ledger.

          
Use public, redacted evidence only. Never send secrets. Never include passwords, recovery phrases, private keys, wallet backup files, or full API keys.
