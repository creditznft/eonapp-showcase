## Important product decisions preserved

- Beginners do not need to know Ollama/LM Studio/Jan. EONBOT starts with a goal, gives one conservative path, links official installers after a tap, and requires a user-triggered scan/self-test after installation.
- For creator content, manual-first works across any destination now. It avoids Cloudflare media relays, referral traffic bottlenecks, user API-key burden, and unsafe token assumptions.
- Direct connectors later use EONAPP-operated OAuth/token custody and a per-post user approval model. Users should not create developer keys.
- No AI auto-posting, background posting, hidden local network probing, browser token storage, silent cloud fallback, or false image/video/voice claims.
