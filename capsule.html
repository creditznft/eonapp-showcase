Create one encrypted Capsule

Every eligible allowlisted local workspace record is collected into this one file. When supported and useful, it is compressed before encryption in this browser; otherwise it stays encrypted without compression. EONAPP does not save the passphrase, and the file is not sent anywhere automatically.

Checking the allowlisted local workspace boundary…

Capsules intentionally exclude API/provider keys, Vault recovery material, wallets, payments, OAuth sessions, rewards/referrals, raw media, model files, caches, and unknown browser storage. Google sign-in identifies an account; it cannot recreate browser-local work without a Capsule or paired device.

Know exactly what survives, moves, restores, and deletes

The Workspace Capsule protects eligible local records. Raw Creator media, encrypted secret records, device-bound identity, temporary session state, and replaceable caches remain separate protection classes so one successful file can never be mistaken for complete device recovery.

Back up this Capsule to Google Drive

After you choose it, EONAPP creates one compressed-when-useful, encrypted Capsule in this browser and uploads that one file to the Google Drive account you select. Google Login does not grant this permission. It never starts sync, automatic backup, or automatic restore.

Google Drive is optional and awaits an explicit backup action.

EONAPP keeps no Drive access credential after this tab is closed. Disconnecting does not delete existing Drive copies; move a selected copy to Drive trash separately.

Inspect-first restore rules

Inspect first. New records are selected as add-only. A same-key conflict is never overwritten unless you select that key separately. Any storage failure rolls back the selected records.

  • Workspace, identity, and Realm records are reviewed before any change is applied.
  • Provider keys, Vault recovery material, wallets, payments, OAuth sessions, rewards/referrals, raw media, model files, caches, and unknown browser storage stay outside the Capsule.
  • Restore remains manual, local, and review-first. Automatic multi-device sync is not active.
