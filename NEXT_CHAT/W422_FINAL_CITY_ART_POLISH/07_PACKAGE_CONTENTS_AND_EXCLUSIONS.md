# W422 Package Contents and Exclusions

The final source archive must include the lean runnable application, W422 source art, generator, contracts, gates, unit tests and handover documents.

It must exclude `node_modules`, `dist`, `.git`, build/report/artifact caches, browser profiles, screenshots except the curated static art contact sheet, archives nested inside the archive, `.env` files, credentials, Cloudflare tokens, OAuth secrets, D1 dumps, R2 credentials and customer data.
