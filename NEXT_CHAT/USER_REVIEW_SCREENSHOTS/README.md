# User Review Screenshots

These screenshots are design evidence, not implementation proof.

## What they show

- Current EONAPP Chat problems: detached/cluttered menus, duplicate utility items, weak guest sign-in discoverability and no clear voice affordance.
- Current EON City problems: primitive visual quality, HUD overload, inconsistent legacy/canonical paths and unproven controls.
- Reference interaction patterns from ChatGPT: compact account popover, Profile modal, Settings modal and clean Apps gallery.

## How to use them

Use them to compare hierarchy, discoverability and information density. Do not copy ChatGPT branding, text, proprietary visual assets or exact layouts. Implement EONAPP’s own graphite/purple visual system and controls.

## Required design corrections

- Google login is a small intent modal, never a Profile/Backup workflow.
- Account actions live in an anchored account popover.
- Settings are one modal, not persistent sidebar clutter.
- Apps are a clean catalog grid/list with one-click launch; disabled/coming-soon states are explicit.
- EON City needs authored assets and only essential HUD controls.
