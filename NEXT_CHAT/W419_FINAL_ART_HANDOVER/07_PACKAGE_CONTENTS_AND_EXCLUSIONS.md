# W419 Package Contents and Exclusions

## Included in source archive

- lean runnable source;
- original W419 SVG art kit and runtime integration;
- all W419 gates/tests/docs;
- source manifest and checksum;
- W419 handover documentation.

## Included in documentation companion

- Codex start guide and execution/deploy runbook;
- art inventory and contact sheet;
- manual device/OAuth/Sync proof checklist;
- roadmap, status and validation receipt;
- changed-file manifest.

## Deliberately excluded

- `node_modules`, `dist`, report caches, browser profiles, screenshots from real devices;
- `.env` and all credential/token/session values;
- Cloudflare D1 exports, R2 data, customer/user data;
- nested ZIPs and stale previous packages;
- unreviewed GLB, KTX2, audio, animation or third-party art.
