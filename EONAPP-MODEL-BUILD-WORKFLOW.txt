12. Prompt template — multiplayer module
-----------------------------------------
Build one P2P multiplayer module for EONAPP.ch.

Context:
- GunDB is already CDN-loaded via p2p-discovery.js — reuse it
- No npm, no Node.js, no backend required for GunDB
- Do NOT use IPFS PubSub (requires kubo daemon)
- Use Google STUN for WebRTC NAT traversal (free, reliable)
- Trust anchor: deterministic game seeds (both players play same seed independently)

Requirements:
- GunDB namespace: eonapp:challenges:v1:{gameId}
- Challenge payload: { gameId, challengerUid, seed, challengerScore, createdAt, expiresAt }
- Challenge URL: encode challenge payload as URL-safe base64 querystring
- Browse open challenges: filter by gameId, sort by recency
- Accept challenge: play same seed, compare scores, determine winner locally
- Earn EONL locally on challenge win
- Rate limit: max 5 open challenges per UID
- TTL: challenges expire after 48 hours

Deliver:
- assets/js/utils/p2p-multiplayer.js (ESM, no npm, GunDB via window.GUN)
- Integration snippet for game win/fail panels
- Integration snippet for games.html "Live Challenges" section
- QA checklist
