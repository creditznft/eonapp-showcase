# Archived Forge pre-AI truth tests

These exact W385–W387 tests record the former local-only Forge contract before W648 introduced the trusted parent-page AI proposal workflow. They are preserved unchanged for archaeology and are intentionally excluded from the maintained release suite because their assertions that AI code edits are unavailable are superseded.

Current certification lives in the maintained W385–W387 compatibility tests plus `w648-forge-ai-builder.test.mjs` and `w648-forge-ai-controller.test.mjs`.
