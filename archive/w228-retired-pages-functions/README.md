# W228 retired Pages Functions boundary

These Pages Functions are intentionally retired and excluded from the active
production tree.

They stay archived-only because the current EONAPP release does not activate:

- rewards
- payments
- EVM or wallet handlers
- referral writes
- ad-reward postbacks
- social posting endpoints
- Telegram session endpoints

The active Pages deployment remains limited to the current reviewed surfaces and
the explicit identity-only/auth-safe functions shipped in `functions/`.
