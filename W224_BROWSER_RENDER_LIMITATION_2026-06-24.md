# W224 Browser Render Limitation

The W224 Playwright specification was discovered and Chromium was launched using `/usr/bin/chromium`. Navigation to the local Vite preview was blocked by environment policy with `ERR_BLOCKED_BY_ADMINISTRATOR`.

No live 3D rendering, input, visual quality, or fallback behavior has been claimed as browser-proven from this sandbox. The handover includes the exact Playwright command and the test specification for execution in a permitted environment.
