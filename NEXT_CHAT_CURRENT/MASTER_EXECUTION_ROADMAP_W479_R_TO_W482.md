### M2: lightweight image-to-video

One proven image-to-video path with bounded output size, visible progress, cancel, failure handling, output validation, and Ready-to-Post handoff.

### M3: Studio Video

Creator-grade video generation/animation workflow. Needs queue state, device fit, thermal/performance truth, output library, export formats, safety/review, and device proof.

High-end local devices only. Explicit hardware/model requirements, large-download/storage guidance, quality tiers, local output proof, cancel/recovery, and no false universal support claim.

Every proven local output becomes a Creator Library asset and can enter the manual-first Ready-to-Post kit. No raw media in Chat/City, no Cloudflare media relay, and no background upload.

Per runtime evidence matrix; physical devices; CSP/CORS/PNA; output/persistence; performance/thermal evidence; support copy.

## W481 — Social publication system

### Universal baseline: Manual-first Ready-to-Post

Works for nearly unlimited platforms without user API keys: post package includes media chosen locally at user share time, caption, title, CTA, hashtags, alt text, first-comment text, format notes, and platform variants. Native share when supported; copy/download/manual upload always available. No Cloudflare media host, referral relay, or hidden tracking.
