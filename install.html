Install EONAPP

Installation depends on your browser and device. The install prompt adds a local app shell for this profile only; it does not create a cloud backup, share keys, copy Vault data, or unlock paid features.

What install does

Local shell and faster return path

The browser may offer a PWA-style install prompt. If accepted, EONAPP opens like a local app for this browser profile. Chat history, Vault data, City progress, and provider settings still remain local unless you export or restore them explicitly.

If no prompt appears

Use the browser menu

Some browsers hide the prompt behind the address-bar app icon or the browser menu. If the button above does nothing, use the browser’s install option or continue from this tab without installation.

Open help

Keep boundaries clear

Install is not backup or sync

Installing EONAPP does not grant Google Drive access, activate sync, copy provider keys, or create a paid entitlement. Use Profile, Vault, Capsule, and Billing for those separate decisions.

Desktop Local AI

One small helper for stronger Local AI

EON Local Companion lets EONAPP connect to approved AI tools already on this computer, start supported local engines after your setup tap, and recover image/video connections without asking you to understand ports or CORS.

Checking this device…
Basic chatPhones, tablets and basic computers can use Local Lite when this browser supports it. No desktop helper is required for that path.
Desktop modelsOn Windows or macOS, EON can reuse a supported Ollama or LM Studio installation after proof. The Companion is offered only when a signed device-certified build exists for that exact platform.
Images & videoOn capable desktops, a certified Companion is the protected ComfyUI connection. Image and Video readiness are checked separately and heavy jobs share the City workload governor.

Offline workspace

Install EONAPP for offline work

The Core pack keeps the EONAPP shell, Local AI setup, local projects, Library, Workspace, Automations, Vault tools, Capsule and local-first pages available in this browser. The Full pack also installs EON City and the current Expanse art after one signed-in online check.

Full City packRequires one explicit signed-in installation. City assets are verified and reused from browser storage.

Checking installed offline coverage…

Offline mode never stores cloud API responses, provider keys, prompts, payment data or account cookies. Unsaved cloud actions are not queued automatically. Removing the offline access pack keeps only reusable public City art so unchanged assets do not need to be downloaded again.
