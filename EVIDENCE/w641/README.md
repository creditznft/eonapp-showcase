# W641 release-governance evidence intake

This directory contains no production authorization by default.

Accepted evidence is redacted metadata only: candidate digests, GitHub run IDs, Cloudflare deployment IDs, Preview URL, environment-protection receipt, prior production deployment ID, and owner-reviewed GO/NO-GO receipt. Never place `.env.local`, Cloudflare tokens, cookies, storage state, provider secrets, webhook signatures, full customer IDs, full emails, or private filesystem paths here.
