## Non-negotiable operating rules

1. Every future package carries this document, `config/eon-master-launch-ledger.mjs`, the exact source delta, validation receipts, next-wave brief, and SHA-256.
2. A source test, compilation pass, static build, canvas boot, or mock asset is **not** user-experience launch approval.
3. Secrets, `env.local`, node modules, browser profiles, raw private prompts, unredacted model replies, generated media, and receipts containing personal data remain out of handover packages.
4. AI grounding is not model training. Personal memory is opt-in, browser-local, and never silently converted to training data.
5. **Client-only AI/research/media policy:** no EONAPP/Cloudflare worker, proxy, server-held provider key, or hidden relay. Browser-direct BYOK paths require provider/browser permission; localhost integrations remain user-installed and loopback-only.
6. Payments, subscriptions, wallets, posting, account changes, social connections, and external actions always require a clear user confirmation and their own release evidence.
