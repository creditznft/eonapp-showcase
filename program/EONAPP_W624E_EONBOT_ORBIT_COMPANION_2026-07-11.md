## Mission completed

W624E turns the existing procedural EONBOT foundation into one useful, captions-first Orbit companion inside the existing W624C Command District. Orbit explains real destinations and proof boundaries without pretending to be a live autonomous agent.

## Companion contract

Orbit exposes exactly nine deterministic local presentation states:

1. `follow`
2. `lead`
3. `point`
4. `think`
5. `speak`
6. `scan`
7. `celebrate`
8. `warn`
9. `help`

The presentation bridge maps those states to the existing companion director and procedural rig. State changes are local visual/caption behavior only. They cannot navigate, execute work, call a provider, read private content or change account/commercial state.

## Honest contextual guidance

- Five non-repeating hints cover the W624C first-sixty-second route.
- Six destination hints map only to the canonical Command District destinations.
- Agent Theatre always uses a warning/proof-gated caption and remains dormant until a genuine receipt exists.
- Project return guidance may use only a bounded saved-project portal count. Orbit cannot see names, files, prompts or project content.
- Help and acknowledgement captions explicitly say that nothing opens automatically and that no success, payment, reward, publication or completed work is being claimed.

## User controls and accessibility

Visible controls provide:

- muted/unmuted presentation state;
- Show Less Guidance;
- Help;
- Dismiss;
- Show Orbit restore;
- reduced-motion adaptation inherited from the user/browser preference.

Captions remain primary. Speech output requires a separate explicit Voice action, and the microphone remains off. The caption shell is non-blocking, while its buttons remain individually interactive.
