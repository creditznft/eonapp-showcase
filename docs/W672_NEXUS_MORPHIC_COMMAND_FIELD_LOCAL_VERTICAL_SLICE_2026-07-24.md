# W672 — EON NEXUS Morphic Command Field local vertical slice

Status: local development only. No GitHub upload, preview, deployment or merge.

## Purpose

Begin the approved N3 direction by replacing the decorative five-node emphasis
with a bounded field of real privacy-projected work objects around the one
existing EONBOT core.

## Included

- project, task, conversation, approval, result, route and tool objects
- stable spatial positions across adapter refreshes
- state-driven morphic composition
- selected-object inspector with explicit existing actions
- same Chat, Projects, Review, Results, Atlas and City callbacks
- mouse, touch, keyboard and voice-compatible interaction

## Not included yet

- webcam gestures
- persistent user-arranged layouts
- comparison canvas
- object grouping
- generated private-content previews
- automatic execution or navigation

All actions remain explicit and the renderer still receives only the existing
privacy projection.
