# W371 — EON City Performance Laboratory

## Delivered source boundary

W371 adds a manual local performance checklist for desktop integrated graphics, desktop dedicated GPU, Android around 4 GB, iPhone Safari, and weak/unavailable WebGL fallback. A tester can explicitly record pass, failed, blocked or not-run status with a short safe note and optional bounded runtime numbers, then export their own local JSON.

## Evidence boundary

No device probe, telemetry, screenshot upload, automatic pass, certification, browser proof, GPU proof, production proof, or launch approval is generated. The checklist starts incomplete and stays non-certifying even if a tester marks every row passed.

## Data boundary

The stored record is limited to case ID, status, a short secret-filtered note and a bounded frame summary. It does not include a device ID, user agent, screenshot, Chat, Vault content, provider information, files, payments, or raw AI output.

## Not a proof claim

W371 does not claim real-device testing, performance certification, all-device support, Lighthouse completion, production deployment or visual certification.
