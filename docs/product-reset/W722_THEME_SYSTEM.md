# W722 — Launch theme system

EONAPP now ships three deliberately different dark launch themes:

- **Graphite** — balanced charcoal, restrained neutral/sage emphasis, and the default appearance.
- **Obsidian** — near-black, high-clarity monochrome surfaces with silver emphasis.
- **Ember** — warm charcoal and espresso surfaces with restrained copper/amber emphasis.

The retired `neon-night` preference migrates to Graphite before first paint. The theme authority updates page background, shell, cards, borders, text hierarchy, focus, buttons, Quick Command Orb, and the City accent token. Blue and purple are not launch themes.
