# W721 — Product reset contract

## Product model

- Familiar 2D workspace for work.
- Full-screen 2D Quick Command surface launched by one Orb.
- Compact 3D Command Hub for presence and discovery.
- Existing 3D Nexus assets remain valuable City assets.
- City stations open the same 2D work components as normal routes.

## Superseded launch assumptions

The maintained launch contract no longer requires:

- a frontend Pulse or Live Nexus on ordinary pages;
- streamed or infinite Expanse at launch;
- district belts as the main launch navigation model;
- a relic-heavy Realm Studio as the first Realm experience;
- separate Help and Support shells.

Superseded tests remain preserved through an explicit non-certifying archive manifest.
