# W393A — Lean Handover Integrity

## Purpose

This continuation source package intentionally contains runnable source, not a
complete historical evidence archive. The previous W238/R3-F1 hash-verified
archive directories are **not packaged** here. Their absence must not be
interpreted as a claim that the historical archive was reverified, nor as a
reason to restore retired transaction, wallet, token, payout, ad-reward, or
legacy social code.

## What W393A proves

- The required Cloudflare/Vite public deployment files exist at the project
  root and match their `public/` copies.
- The active app import graph does not reach retired commercial/value systems.
- Retired active paths remain absent, including referral cloud storage, wallet
  configuration, reward/ad code and old Creator Studio runtime.
- The current invite architecture remains inactive and read-only.

## What W393A does not prove

- It does not hash-verify historic archive files that are absent from this lean
  handover.
- It does not certify a past release's old evidence board.
- It does not activate referrals, D1 writes, rewards, payment rails, social
  OAuth or publishing.

Use `npm run qa:w393a-lean-handover-integrity` for current-source proof. A
separate source bundle that contains the historic archive is required for a
forensic R3-F1 archive verification.
