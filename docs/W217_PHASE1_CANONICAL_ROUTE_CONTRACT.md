# W217 Phase 1 — Canonical Route Contract

**Status:** Implemented and source-gated on 24 June 2026.

## Purpose

Phase 1 removes conflicting public-route behavior and makes one module the source of truth for Cloudflare Pages redirects, Vite development/preview rewrites, static-link auditing, PWA route checks, and route tests.

The contract lives in `config/route-contract.mjs`. Do not hand-edit `_redirects` or `public/_redirects`; run:

```bash
npm run routes:sync
npm run qa:w217-route-contract
npm run gpt55:route-truth-device-audit
```

## Informational/trust routes

`/about`, `/privacy`, `/terms`, `/legal`, `/support`, and `/billing` are explicit 200 rewrites so clean URLs used by sitemap and canonical metadata remain deployable.

## Compatibility routes

- `/telegram` and `/rewards` remain explicit disabled surfaces, outside primary navigation.
- `/referral`, `/r`, `/m`, and wildcard forms retain stateless signed-share compatibility.
- `/u/:handle` is represented by Cloudflare wildcard syntax `/u/*` and serves the future public Realm profile surface. It does not activate public commerce, payouts, or user storefronts.
- `/archive` is the safe destination for retired commercial/token/mission pages.

## Retirements made in this wave

- `/automation`, `/automate`, and `/automation-studio*` now have one destination: `/automations`.
- Legacy Cockpit/builder pages resolve to `/workspace`.
- Legacy Marketplace routes resolve to `/market`.
- Legacy Realm/RealmWorld/team realm pages resolve to `/eoncity`.
- `/trade/sandbox*` resolves to `/trade`; there is no parallel trading product.
- Legacy setup/device routes resolve to `/local-ai` or `/chat`.
- Legacy subscriptions, reward/payment dashboards, token dashboards, social missions, and historic games resolve to `/archive` or the relevant safe surface.

## Invariants

1. Every redirect origin appears exactly once.
2. Root and `public/` redirect files are generated byte-for-byte from the same contract.
3. Tests verify behavior through exported contract data, not repeated hard-coded Vite route literals.
4. No localStorage or IndexedDB migration, deletion, or storage schema changed in this wave.
5. Rewards, payouts, ads, token, payment, and user commerce paths remain disabled.

## Required live proof before production deployment

This environment completed source/build verification only. In a permitted browser/CI environment, capture desktop, mobile portrait, and mobile landscape proof for canonical routes, every 301 alias group, PWA update behavior, and a Cloudflare Pages preview. Verify that no redirect loop occurs on production.
