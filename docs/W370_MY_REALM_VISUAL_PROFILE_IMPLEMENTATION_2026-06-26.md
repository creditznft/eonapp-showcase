# W370 — My Realm Visual Profile

## Delivered source boundary

W370 adds a compact local visual profile for a saved Realm: theme, landmark, companion shell, atmosphere and project-display preference. It can be encrypted into a user-downloaded backup file with a passphrase that EONAPP never stores.

## Data boundary

The visual profile contains only a Realm ID plus allowlisted presentation choices and an update time. It does not contain a Realm label or handle, chat, Vault material, provider keys, local files, project content, payment data, wallet information, a passphrase, or an account record. Google Login does not back this up and no cloud upload occurs.

## Explicit limits

No GLB, texture, final companion model, public publishing, cloud sync, wallet, payment, marketplace, global handle registry, or public Realm directory is included. The companion and atmosphere choices are source-controlled visual preferences for current/future City presentation, not claims that final art assets are loaded today.

## Not a proof claim

W370 does not claim browser export/import proof, passphrase recovery proof, accessibility certification, asset-integration proof, real-device proof, final visual quality or production deployment.
