# W419 — EON City Original Vector Art Pack

## Delivered in source

W419 provides an original EONAPP-owned visual pack for the current Babylon procedural City:

- wet-street, brushed-graphite, glass-grid, carbon-weave and neon-circuit treatments;
- wide neon skyline-depth backdrop;
- EON monogram, EONBOT halo and seven district emblems;
- cyan, violet and mint route decals;
- quality-tier selection: Lite preserves the essential wet-street, EON identity and route readability; Balanced/Cinematic add façade, glass, skyline and district texture layers;
- Babylon integration for street, plaza, Arrival Gate, Command Centre, Creator Atrium, Forge Bay, Metropolis districts, skyline depth and local wayfinding;
- same-origin static delivery from `/assets/city/art/` and texture cleanup when Immersive Work Mode closes.

## Provenance and release boundary

Every SVG in `assets/city/art/` is source-authored original EONAPP vector work. The W419 gate checks each file SHA-256 against the runtime catalog and checks that the build copies the directory to the deployed public asset tree.

This is **shipped visual source art**, not a final GLB/KTX2 asset release. W417 remains required for any final binary environment/character asset: original or commissioned provenance, licence review, SHA-256, LOD0/1/2, KTX2/Basis textures, art review, visual QA and target-device performance evidence.
