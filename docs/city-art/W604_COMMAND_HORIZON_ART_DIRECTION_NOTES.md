# W604 — Command Horizon Material Direction Notes

## Visual target

Command Horizon should read as a high-end cyber-noir productivity district, not as a generic neon toy set:

- **Graphite metal** carries the city’s institutional, serious base;
- **wet-surface variation** suggests rain and atmosphere without needing screen-filling reflections;
- **brushed directionality** breaks flat procedural surfaces and makes landmark scale legible;
- **cyan emissive routes** are reserved for current, direct, useful interaction; and
- **violet anomaly light** remains for later exploration/expedition content, not general UI noise.

## Material rules

1. Base material contrast must support readable silhouette before bloom, post-processing, or neon glow.
2. Every emissive line must correspond to an interaction, route, status, or architectural edge—not decoration by default.
3. Texture scale is intentionally restrained. No camouflage noise, grime fetish, giant logos, or visual clutter.
4. Command Deck should feel heavier and more exact than Arrival Gate; Wayfinding should be the brightest but smallest visual element.
5. Textured assets are still candidates. Do not call the City AAA or final until real device imagery is approved.

## What follows W604

W605 should add authored KTX2/Basis compression only after a real asset toolchain exists. W606 should create custom texture families for Navigator, EONBOT, and the first three NPC archetypes. W607 should then judge all assets together in the actual camera, lighting, and interaction flow rather than in isolated files.
