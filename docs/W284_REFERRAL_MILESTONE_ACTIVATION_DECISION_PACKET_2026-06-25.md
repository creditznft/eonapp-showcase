# W284-A0 — Invite/referral and access-milestone activation decision packet

## Present state

**Not authorised.** Invite context may exist locally, but referral rewards, access milestones, D1 writes, reward settlement and claims remain disabled and fail closed.

## CEO decision

The existing Cloudflare D1 database may be considered as a future **pseudonymous non-financial audit ledger only**, not as a wallet, payment, payout, token, coin, points, commission, revenue-share or automatic-entitlement system.

No activation decision can be made from source code, a dashboard toggle or a pre-existing database. W284 needs an explicit separately reviewed decision after the evidence below is complete.

## All approvals required

- Exact non-financial product definition: what user-visible capability is offered, its expiry/reversal and no-value wording.
- Legal/consumer/referral review for the target jurisdictions.
- Privacy: notice, consent, retention, deletion/export, no raw IP and no device fingerprint.
- Security: server authority, idempotency, replay/abuse controls, rate limits and test evidence.
- Support: disclosure, appeal/reversal process, owner and customer recovery path.
- Preview evidence: real binding inventory, schema review and safe rollback/kill-switch drill.
- Named accountable owner for the program and an observed incident/rollback drill.

## Never activate under this packet

- Wallet, custody, seed phrase, private key, browser signing or on-chain reward flow.
- EON Lite Coin/token/points/price, cash, payout, commission, revenue share, exchange rate or investment language.
- Client-side grant authority, raw click/share/ad-view qualification, automatic claims, hidden tracking, raw IP storage or device fingerprinting.

## Future safe first pilot shape — only after all approvals

A single non-financial, non-transferable, clearly expiring capability with server-side verification, one account-to-inviter association, idempotent append-only event records, visible disclosure, support/reversal reason and a tested kill switch. This is a future proposal—not a current implementation or approval.
