# W655 — Complete Roadmap and Stop Rules

1. Package integrity and source receipt.
2. Local W655 audit, focused runtime tests and full maintained suite.
3. Exact-dist Preview deployment.
4. Clean signed-out boundary proof.
5. Real Google-authenticated boot proof.
6. Command Room route/review matrix.
7. Realm, Local AI and every district/terminal matrix.
8. Controls parity on desktop, touch, mobile and controller.
9. Character/prop/material/animation visual audit.
10. Cold/warm/update/cache and fallback proof.
11. Performance, memory, long-session, context-loss and accessibility proof.
12. Full EONAPP Preview regression.
13. Machine evidence validation.
14. Owner visual review and score.
15. Guarded production deployment.
16. Production smoke and rollback confirmation.
17. Final evidence return package for ChatGPT review.

## Scoring policy

Ten categories: entry, Command Room, route/work coverage, productivity/entertainment balance, districts/Realm, art/animation, controls/mobile, performance/cache, safety/accessibility, recovery/operations.

Pass requires:

- every category >= 9.0;
- overall >= 9.5;
- critical defects = 0;
- high defects either 0 or explicitly owner-accepted with a dated remediation plan;
- exact candidate digest matches;
- machine evidence validator passes;
- owner explicitly approves production.

## Stop immediately when

- package/digest differs;
- a secret appears in source, dist, screenshot, HAR or log;
- signed-out City requests heavy/private assets;
- authentication is bypassed or loops;
- controls are inverted or inaccessible;
- City crashes, boots blank or loses all state on route return;
- a terminal performs work before review;
- Realm implies public publishing or Market implies financial trading;
- console has uncaught exceptions;
- production would deploy without exact owner GO.

## Return package from Codex

Codex returns one ZIP with evidence files, machine validation receipt, scorecard, defect register, Preview and production deployment receipts, screenshots, videos, HARs, console logs, traces and a concise recommendation: GO, NO-GO, or GO-WITH-RECORDED-NONCRITICAL-ISSUES.
