# W366 — Neon Command District vertical slice

## Decision

W366 turns the first Babylon district from a navigation proof into a more intentional **authored procedural vertical slice**. It is the first of many City districts, not a claim that EON City has become a final AAA game.

The vertical slice focuses on one complete work-oriented loop:

1. Enter Arrival Plaza.
2. Approach the Command Centre and meet EONBOT.
3. Choose a visible work landmark: Build Workshop, Knowledge Archive, Realm Relay or Local AI Observatory.
4. Request a route review.
5. Choose separately whether to open the native work surface.
6. Return to the City only through an existing local receipt path.

## Delivered in source

- Original procedural Arrival Plaza framing, Command Centre entry detail, Command Room preview, terminal grouping, guide pylons and readable district lanes.
- Refined procedural hero Operator and EONBOT silhouettes.
- Six named City guide roles, each tied to one local landmark and a written truth rule.
- A compact local `First Command Route` state. It stores only an allowlisted stage, landmark ID and count. It does not store user-written content, prompts, outputs, provider information, files, credentials, purchases or remote identifiers.
- A visible mission card in Immersive Work Mode that explains the next step without fake quests, points, rewards or pressure.
- Existing City route review remains mandatory. Babylon may prepare a route but does not navigate, open a native page, execute a task or approve a result itself.

## What W366 does not claim

- No GLB, GLTF, texture, animation, audio, cinematic, licensed character pack or external game asset is supplied in this wave.
- No final character acting, facial performance, skeletal animation, combat, multiplayer, economy, simulation, live agent system, background task execution or public Realm discovery exists.
- Procedural geometry is still a source-controlled fallback. Future high-grade art must pass W365 provenance, SHA-256, human visual review, asset budget and device proof gates.
- Source validation is not real-device or human visual evidence.

## Art direction

**Neo-noir operational sanctuary**: wet steel, calm controlled accents, strong landmarks, legible paths and a lived-in command district. EON City must remain original. Do not copy art, characters, signs, mission patterns, UI, music or assets from Cyberika, Titan Quest, Inotia or any other game.

## Truth and privacy rules

- City renders only public landmark labels and bounded local journey status.
- EONBOT and guide characters are navigational metaphors, never claims that a provider or agent is working unless a separate truthful local receipt exists.
- Chat, Workspace, Projects, Realm Studio and Local AI remain the owners of their own private work. City receives no prompt, raw output, key, model, file or Vault content.
- No rewards, tokens, wallets, purchases or referral activity belongs to the command route.

## W367 handoff

W367 rebuilds **Three.js Spatial Command Space** using the same Command District identity, role names and route boundaries. It should provide premium command-room composition and visual work summaries, but never duplicate raw work content or add a second automation engine.
