# EONAPP R4 W379 — Final CEO Decisions and Launch Blockers

**Snapshot:** source-only, cumulative through W379.  
**Purpose:** the single executive reference for Codex merge work and owner-only launch decisions.

## Product shape

EONAPP is a guest-first, local-first AI work environment:

- **EONBOT** is the conversational entry point.
- **Workspace** holds local Projects, artifacts and work plans.
- **Apps** is the main product catalogue: Workrooms, Blueprints, Insights & Forecasts, AI Crew and Connections.
- **EON City** is optional visual navigation and a return loop, never a required paywall.
- **Market Intelligence** stays under Apps/Insights and `/trade` remains a compatibility deep link. It is manual/CSV research only; no broker/exchange credentials, orders, execution, live data claim, paid financial recommendation, money-backed prediction, or cash value.

## What is implemented in source

- Graphite is the default theme for new/undeclared preferences; Classic EON remains opt-in.
- Apps has 32 free official versioned Blueprints and 16 approval-first local workflows.
- A Blueprint handoff prepares a local Project, Library template and workflow draft.
- Market Intelligence uses local manual/CSV data, research notes, historical scenario review and a private, non-economic Forecast Studio.
- Google Login code is optional, identity-only and fail-closed; guest use remains available and it never creates a backup claim.
- Current R4 source, lint, tests, production build, smoke, static audit, secret scan and readiness gates pass.

## AI-first support boundary

No live chat agents, calls, onboarding team or managed support desk are planned. EONBOT, in-product diagnostics, searchable help, billing portal actions and automated access checks should handle routine use. An owner-only asynchronous exception path is still required for access errors, security/privacy matters and payment disputes; it cannot truthfully be outsourced away by an AI label.
