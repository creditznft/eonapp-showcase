# W668 — Flagship Living Nexus

## Decision

EON NEXUS is one visual intelligence that changes form, not three unrelated products:

1. **Pulse** — a compact persistent signal.
2. **Expanded Nexus** — the main Jarvis-like productive workspace.
3. **Spatial Living Nexus** — the same intelligence embodied in EONCITY.

All three consume the same privacy-projected Nexus snapshot and preserve the same continuity identity, meaningful node order, state, colour system and morph signature.

## State-driven visual language

Observable EONBOT states change the actual form rather than only changing a label:

- Ready — calm orbital core.
- Listening — receptive wave.
- Working — reasoning helix.
- Speaking — voice ripple.
- Approval waiting — decision gate.
- Complete — resolved star.
- Error — fractured signal.
- Offline — dormant core.

The projection exposes at most five meaningful nodes. It prioritizes selected, active, waiting and failed work while keeping stable node identity and placement between surfaces.

## Truth and safety boundary

W668 does not create another assistant, conversation store, project store or task store. It does not read prompt bodies, files, credentials or private project content. It cannot start AI work, voice capture, navigation or approval. It only visualizes the existing bounded Nexus projection and leaves all consequential actions explicit.

## Acceptance status

Source and focused local tests can certify projection identity, state logic, node stability and frontend integration. They do not certify 9.5/10 visual quality. Final acceptance still requires the emitted build and real-browser inspection of Pulse morphing into Expanded Nexus and the same state appearing in EONCITY.
