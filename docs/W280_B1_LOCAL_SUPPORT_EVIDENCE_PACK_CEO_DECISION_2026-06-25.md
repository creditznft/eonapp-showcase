# W280-B1 CEO decision — local support evidence pack

## Product role

A local support evidence pack makes self-service support easier without creating hidden telemetry or implying an operating support desk.

## Required behavior

1. The user chooses a canonical support topic and writes only expected/actual observations.
2. The route is captured as a same-app pathname only; query strings and fragments are excluded.
3. Device/browser context is reduced to coarse labels; no raw user-agent is exported.
4. Text is automatically redacted for common secret-like patterns and full URLs.
5. The person previews the exact JSON and explicitly confirms review before copy/download becomes available.
6. EONAPP never sends, stores, queues, files, or evaluates the pack.

## Not a claim

This is not a support ticket, security disclosure program, incident-response channel, legal record, privacy consent mechanism, service-level agreement, or human response promise.

## External evidence still needed

Before any public support/escalation claim: named support owner, actual channel, incident/recovery drills, device/accessibility review, legal/public-copy review, privacy/security review, and W260 board closure.
