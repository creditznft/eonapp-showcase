# W677 — reviewed Transit Capsule journey

Status: local source only.

W677 turns the Orientation Hall Capsule from a decorative vehicle into the visible interface for the existing review-first district travel contract. Every destination still requires review and a separate confirmation. The user may choose a short visible Capsule ride or the accessible instant skip path. The journey animates only one existing Core Capsule, moves no player before confirmation, opens no route, transfers no private data and creates no second render loop.
