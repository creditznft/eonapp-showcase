## Whole-site performance plan (A2 / W282)

1. Build and generate the route inventory: `npm run build && npm run lighthouse:routes`.
2. Prove every inventory route has local delivery/redirect continuity: `npm run qa:r3a2-all-public-routes-static`.
3. Collect real Lighthouse desktop and mobile reports in a normal browser-capable environment: `npm run lighthouse:desktop` and `npm run lighthouse:mobile`.
4. Triage canonical pages first: `/chat`, `/`, `/eoncity`, `/market`, `/vault`, `/tools`, `/telegram`, `/support`, `/privacy`, `/about`; then resolve aliases/redirects.
5. Archive raw JSON/HTML reports outside Git, record scores/budgets in a redacted evidence index, and repeat in Preview/live before W260 can change state.

In this ChatGPT sandbox, managed Chromium blocks URL navigation before tracing; static delivery is proven, but no Lighthouse score is claimed. Codex must execute step 3 locally.
