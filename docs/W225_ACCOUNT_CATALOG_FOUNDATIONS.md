# W225 Account, Public Realm, and Official Commerce Foundations

W225 establishes future server-side contracts without treating the browser as a source of account, publication, purchase, receipt, payout, or token truth.

## Current truth

- A profile is local to this browser.
- A My Realm is local to this browser, with a signed portable identity link only.
- The official Market panel is disabled.
- No referral click is tracked and no share link creates commercial attribution.
- No feature transmits account, Realm, or payment data in W225.

## Future implementation boundary

A real public Realm requires a verified server account, server-side handle/anti-impersonation validation, terms acceptance, a report/takedown path, an audit trail, a cache/version policy, and a public-data allowlist.

A real official catalog requires EONAPP merchant/publisher identity, server-authoritative catalog/order/receipt/delivery/reversal records, support and dispute handling, and a server-side ledger. A client-side success callback is never a receipt or delivery proof.

## Data excluded from future browser-generated public proposals

- Vault material, recovery data, credentials, API keys, wallets, and payment data.
- Private chat, private City layout/state, and local Market moodboard/showcase selections.
- Affiliate attribution, commission, payout, and token fields.
