# W285-A0 — Local AI/device support evidence plan

## Source baseline completed

- Local AI presents non-telemetry device-health guidance: EONAPP does not measure device temperature, battery health, actual free storage or other-app memory pressure.
- Hardware signals are advisory only. The product gives a conservative route, not a compatibility or performance claim.
- Model/runtime actions remain user initiated. Local runtime discovery/self-test only uses an approved loopback endpoint, and the app never installs software or downloads a model.
- Existing device readiness exports are local test records, not fleet or physical-device proof.

## Required external evidence

1. 4 GB-class Android walkthrough: portrait Chat, 2D City, Local AI guidance and a safe exit.
2. Desktop walkthrough: scan an already-installed loopback runtime, run the neutral self-test, select and clear it, and verify the truthful status.
3. Human support review: confirm storage/heat/battery stop conditions and no device-performance promise.

## Claim boundary

This does not certify device support, model performance, thermal safety, accessibility, storage, PWA installation, Local AI availability, or a public launch. W260 remains NO-GO.
