# W288-A0 — Creator project handoff integrity evidence plan

## Implemented source boundary

- Projects can inspect a bounded local JSON ordinary-work handoff before a person opens it elsewhere.
- The parser is pure and review-only: no Project write, import, merge, restore, overwrite, publication, delivery or cloud call occurs.
- It accepts only the canonical ordinary-work schema and rejects direct-import claims, automation/value/identity state, unrecognized fields and secret-like content.
- Encrypted Vault backup remains the separate recovery path.

## Required independent evidence

1. Desktop/mobile file-picker, readability and error-state walkthrough.
2. Content/legal review of no-import, no-ownership and recovery wording.
3. Observed encrypted Vault backup/restore drill for normal project records.

## Non-claims

This is not an import, restore, merge, collaboration, publication, delivery, rights, legal-ownership, device or launch result.
