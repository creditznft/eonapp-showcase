How to Run AI Missions for Free

Connect two free API keys and you have access to some of the fastest AI models on Earth — no subscription required.

5 min read · EON WorkBench guide · ← Back to blog

EON WorkBench is a browser-based AI mission runner. You write a goal, pick a mode, and it executes using whichever AI provider you've connected. The catch most people miss: the best providers are free, and setup takes under 4 minutes.

What you need before you start

  • A Groq account (free) — console.groq.com
  • A Google account for Gemini API (free) — aistudio.google.com

Both give you API keys with generous free tiers. Groq runs Llama and Mixtral at extremely fast inference speeds. Gemini Flash is Google's fastest model and is free up to 1,500 requests/day.

Step-by-step setup

Step 1 — Get your Groq key

Go to console.groq.com → API Keys → Create API Key. Copy it to your clipboard.

Step 2 — Get your Gemini key

Go to aistudio.google.com/app/apikey → Create API key → select any project. Copy it.

Step 3 — Paste both into WorkBench

Open Get Free AI Power and paste your keys into the Groq and Gemini fields. Hit Save Keys. That's it.

Step 4 — Run your first mission

Go to Build. Pick a mode (Ask, Build, Create, Operate, Trade, or Realm) and type your goal. WorkBench auto-selects the best available provider for that mode.

💡 Tip: For long-form writing or structured output, Gemini Flash tends to produce better formatting. For raw speed (brainstorming, rewrites), Groq + Llama 3 is hard to beat.

The 6 mission modes explained

  • Ask — Research, Q&A, explain concepts
  • Build — Code generation, architecture planning
  • Create — Content writing, hooks, copy
  • Operate — SOPs, checklists, system design
  • Trade — Market research, investment thesis generation
  • Realm — Community strategy, realm management

Earning Pool Points while you work

Every mission you complete earns Pool Points. Pool Points determine your share of the EonLite mint pool — the more you use the platform, the larger your allocation when EonLite is distributed. You can track your points in the Vault.

Want even faster AI? Add local models

If you have a decent computer (16GB+ RAM), you can run AI models locally using Ollama. WorkBench auto-discovers local models at startup — no configuration needed.
