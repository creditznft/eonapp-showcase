How to make Local AI ready in EONAPP

One beginner-first path for private on-device AI, with technical controls kept in Advanced.

5 min read·Local AI guide·← Back to blog

Start in EONAPP and choose Make Local AI ready. EON checks the safest path this device can actually support. Local mode never silently switches your prompt to a hosted provider, and software or model downloads remain visible choices.

Phones and tablets: start with Local Lite

On a compatible iPhone, iPad or Android browser, EON Local Lite can run a small reviewed text model inside the browser after you approve the first model download. Desktop runtimes and Companion installers are not offered on phones or tablets, and heavy local Image or Video generation is not implied.

Windows and macOS: reuse what is already installed

On a desktop, EON can test supported local runtimes such as Ollama, LM Studio or Jan after you start setup. A saved runtime name is not treated as proof: EONBOT uses it only after the current runtime and model pass the local self-test.

If EON Local Companion is available for your platform, EONAPP offers it only when that exact package is signed and device-certified. A developer launcher or unsigned test package is never substituted for a consumer installer.

Images and video are separate checks

Local image generation uses the reviewed ComfyUI path on capable desktops. Local Video has its own model, workflow, storage and device gate. A working Chat model never unlocks Image or Video by implication, and EONAPP coordinates heavy local media with EON City so the GPU is not silently overloaded.

You should not need ports or CORS for normal setup

The beginner flow is designed around one setup action. Ports, loopback endpoints, pairing recovery and runtime diagnostics stay under Advanced. If a runtime or browser cannot pass the safe local path, EON explains the blocker instead of weakening security or changing providers automatically.

What works offline?

Local Lite can continue after its reviewed browser assets are actually cached and the browser keeps them. Desktop Local AI can continue while its verified local runtime is running. Browser storage can still be evicted, so EONAPP reports offline readiness from real local proof instead of promising it universally.
