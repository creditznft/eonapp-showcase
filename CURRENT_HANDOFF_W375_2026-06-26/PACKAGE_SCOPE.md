# Package scope

This package contains the runnable W375 source, Vite/package files, current tests, Cloudflare Functions/configuration templates, archived source needed for quarantine verification, safety gates, CEO decisions, and fresh-chat runbooks.

It intentionally excludes `.env*`, secrets, OAuth values, Cloudflare Secrets, tokens, browser/session data, `node_modules`, `dist`, generated test/browser output, logs, local IPNS configuration, and bulky historical QA media.

The package is source-ready. Install dependencies and recreate `dist` from source using the included runbook.
