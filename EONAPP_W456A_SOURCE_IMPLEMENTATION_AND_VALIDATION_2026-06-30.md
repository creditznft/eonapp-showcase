# W456.1 Source Implementation and Validation — EON Noir Readable Guide Cast

## What was implemented

W456.1 replaces the City’s generic guide-marker presentation with an original, source-controlled EON Noir procedural guide kit. It has five named, local-only characters:

- Builder — workshop harness, asymmetric shoulder fins and utility pack;
- Curator — archive halo and mantle panels;
- Guardian — ceremonial mantle wings and beacon ring;
- Device Technician — technical headset, local diagnostic core and device satchel;
- Support Navigator — collar ring, review badge and return marker.

Balanced and Cinematic profiles construct a readable face language from an original visor, twin eye lamps and a mouth cue. Lite uses a deliberate silhouette-only reduction, so low-detail devices are not falsely promised the full detail level. The Babylon City renderer keeps existing local idle motion and route-review boundaries; the kit itself cannot fetch assets, send telemetry, read private data, navigate, create work, make a payment decision or report fabricated task/payment/reward status.

## Validation performed locally

```bash
npm run qa:w456a-noir-readable-guide-cast
node --test tests/unit/w456a-noir-readable-guide-cast.test.mjs
```

The dedicated source gate checks the five required roles, readable Balanced plans, intentional Lite reduction, original procedural status, Babylon wiring, absence of remote/binary loaders and absence of product/payment/reward status claims.

## Not claimed

This is a procedural source bridge, not final NPC production. It does not claim licensed/rigged GLB/glTF character models, animation clips, final LODs, voice or proximity interactions, real-device visual/thermal proof, accessibility review of the rendered characters, human art approval or launch certification.
