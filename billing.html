EONAPP subscriptions and EONKEYS unlock EONAPP workflows and product capability. Image, video and other AI execution uses your local runtime or your own external provider/API key.

Prompts, provider keys, reference files and generated media do not pass through an EONAPP Cloudflare generation backend.

Checkout, renewal and cancellation

Checkout is created only by the same-origin server route after sign-in and opens on Dodo Payments. Access changes only after a signed server webhook updates the entitlement ledger.

Renewal, cancellation, expiry, refund and dispute events are handled server-side. Keep the Dodo receipt and use Support with redacted evidence when help is needed.

Refund, withdrawal, cancellation and disputes

Cancel future renewal through the verified Dodo customer portal. Trial eligibility is account-scoped and can be used only once.

For a duplicate charge, withdrawal request, refund request or dispute, create a private billing case. The case is reviewed against applicable law and Dodo evidence; it does not automatically change the charge or entitlement.

Privacy and local work

Google Login identifies the account used for billing entitlement. It does not automatically back up local Chat, projects, Vault data, City progress, provider keys, prompts or generated media.

Create an encrypted Portable Workspace Capsule for local work you cannot lose.

Payment safety

Never send card data, passwords, API keys, one-time codes, recovery phrases or funds through chat or support. Use only the hosted checkout opened from this page.

Crypto, direct wallet payment, NFT purchase, referral payout, ad reward and offerwall payment paths are not EONAPP subscription rails.
