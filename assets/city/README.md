# EON City local asset boundary

`assets/city/` contains source-controlled EONAPP City assets for the canonical
Babylon route at `/eoncity`. W419 vector art remains as a local fallback layer;
W602–W604 add local same-origin GLB **engineering candidates** for the Navigator,
EONBOT, Arrival Gate, Command Deck, and Wayfinding kits. They do not fetch remote
content, embed user data, or create any provider/account connection.

The current candidates are intentionally **not final art approval**. They carry
local catalog paths, hashes, provenance records, LOD variants, and safe procedural
fallbacks, but they still require KTX2/Basis final packaging (or an approved
exception), human art/licence review, browser/device visual and performance
evidence, the authenticated City closeout, and owner visual approval.

No source in this folder may use a remote network asset path or contain user
content. New candidates must first be listed in the W365 catalog and W406B intake
ledger, then pass W417's local hash/LOD/provenance preflight before they can ever
receive final visual-release approval.
