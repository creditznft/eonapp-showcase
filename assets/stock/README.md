# Stock Video Inputs (License-Safe Only)

Place only assets you own or are explicitly licensed to use for commercial social publishing.

Accepted formats:
- .mp4
- .mov
- .mkv
- .webm

The social video builder may use the first two files in this folder for intro/outro segments when a stock-enabled template is selected.

Do not include:
- copyrighted clips without license
- downloaded social media reposts without permission
- third-party gameplay footage without explicit rights
